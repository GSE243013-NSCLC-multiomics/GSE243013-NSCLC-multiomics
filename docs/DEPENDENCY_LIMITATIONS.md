# Dependency Limitations

## Overview

This document describes the limitations of dependency management in this repository. A complete `renv.lock` file was not generated due to several technical constraints.

## Why renv.lock Is Incomplete

### 1. Binary Package Dependencies
- BPCells requires binary installation on ARM64 macOS
- Binary packages cannot be locked to specific commit hashes
- Installation depends on system libraries and compilation environment

### 2. GitHub Packages
- BPCells installed from GitHub (`dcoulter/BPCells`)
- No stable commit hash tracking for reproducibility
- Package may be updated after this analysis

### 3. Platform-Specific Packages
- R libraries installed in `~/Library/R/arm64/4.6/library` (macOS ARM64)
- Path differs on Linux x86_64 and Windows
- `path.expand()` used for portability

### 4. Large Binary Files
- edgeR object RDS files (60-113 MB each) not included
- BPCells column-major format (20+ GB) not included
- These are generated by the pipeline, not locked

## Manual Installation

If you need to install packages manually:

```r
# Bioconductor packages
if (!requireNamespace("BiocManager", quietly = TRUE))
    install.packages("BiocManager")
BiocManager::install(c("edgeR", "fgsea", "SummarizedExperiment"))

# CRAN packages
install.packages(c("metafor", "survival", "survminer", "digest",
                    "readr", "data.table", "ggplot2", "pheatmap",
                    "RColorBrewer"))

# GitHub packages
if (!requireNamespace("remotes", quietly = TRUE))
    install.packages("remotes")
remotes::install_github("dcoulter/BPCells")
```

## Version Locking Strategy

Rather than using renv.lock, this repository relies on:

1. **Documented versions** in `resources/resource_versions.tsv`
2. **Session info** logged at each pipeline step
3. **Package version checks** in Step 00
4. **Manual installation guide** above

This approach is less automated but more transparent about what is locked vs what may vary.
